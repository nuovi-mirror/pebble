The compiler is a highly experimental frontend for the Pebble programming language. It is
not in a release or stable place and is meant as a human frontend language compiling down
to the textual bytecode language known as Pebble. More documentation will be written once the
interface is stable, however currently it is just the source code at compiler.zig or compiler/
if it is moved. This is not intended to replace the Pebble language, but simply be a mapping
from a higher level language down to Pebble and run on the Pebble VM.

Varable syntax
	varname = modifier operation

	eg. x = 12
	
	Current operations support mathematical expressions documented by the VM.
	Syntax with modifer of the char '`' mark an expression, known as a literal
	in Pebble.

	eg. x = `1 + 2

Function syntax
	fn funcname ( funcargs ) funcreturnvar {
	funcbody
	}

	eg.

	fn foo ( bar baz ) bal {
	bal = `bar + baz
	}

	this creates a function names foo taking args bar and baz and returning the
	variable bal.

	Functions can be called with syntax
	call funcname ( funcargs )

	eg. call foo ( 1 2 ) 
	calls function foo with arguments 1 as 1 and 2 as 2. With the defined function
	foo, this will return the value 3 (AKA 1 + 2, or arg1 + arg2, or bar + baz - 
	however you wish to phrase it).

	Functions can return early with syntax
	return value

	where value is the value to be returned.

Escape syntax
	. op

	eg. . New x '3'

	this will simply inject Pebble code straight into the output instead of treating
	it as a compiler expression.
