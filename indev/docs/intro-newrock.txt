New Rock is a language designed to be readable, simple, and low on
boilerplate syntax. Since New Rock compiles down to Pebble Textual
Bytecode, any platform that has a Pebble runtime or interpreter
can run code generated by a New Rock compiler. For a list of supported
platforms, please visit http://pebblevm.org/platforms.html. A New Rock
compiler can be downloaded alongside a copy of Pebble at
http://pebblevm.org/download.html.

This guide shall act as a brief introduction to the New Rock language
and allow the reader to being writing basic New Rock programs. This
document does not discuss Pebble or advanced concepts using Pebble,
as those are out of the scope of this document. For more info on said
operations, please refer The Pebble Virtual Machine Systems' Programmer's
Handbook and The Pebble Bytecode Specification.

Let's start with a basic program, such as requesting some text to be 
printed to the operating system's standard output buffer.

	include stdlib

	fn main ( ) ret {
		ret = '0'

		call std.io.print ( 'Hello, World!' )
	}

In this example, the first thing we do is request the compiler to include
the New Rock standard library. The Include keyword is used to compile
another file containing New Rock source code with this one. The keyword
can be thought of similar to the C #include statement. This does mean it
is both a preprocessor function and position-dependent. However, in New
Rock, it is safe to define a function more than once, so it is safe to
include the same file more than once. In the case where a function is
defined more than once, the most recent definition relative to the calling
line in question gets priority over previous definitions. In short, if I
were to define a function and call it, then define it again and call it
again, the first call would run the first definition of the function, and
the second call would run the second.

stdlib is a special include, as when this file is included, it is
not searching for a file named stdlib, but instead including the
compiler-provided standard library code.

The next thing we do is define a function named main. Main is a special
function, as it is the program entry point. The main function is where
the program will begin executing from. Functions are defined using
the fn keyword. In New Rock, the opening and closing parenthesis is used
to show the arguments the function is to accept. Arguments are separated
by spaces, not commas, and there should be a space between the last and
first argument and the parenthesis closest to it. This means something
like

	fn main (a b) ret {

is invalid, since the spaces are missing, while something like

	fn main ( a b ) ret {

is valid. In the second case, the function main takes two arguments, which
can be represented inside of the main function as the variables a and b.

The opening brace marks be beginning of the function body. The spacing
before a line in a function does not matter, as the braces are used
to determine where it starts and ends.

The word 'ret' is used to represent the variable returned by the function.
In New Rock, the returned variable is described explicitly in the function
definition, rather than needing to return a variable explicitly. When the
function returns, whatever is in that variable at the current time is
returned.

Here, since the main function is never called, we do not need to return
a value, so we simply define a variable to the literal zero. In New Rock,
single quotes are used to represent a literal value. 

The call statement is used to call a function. Here, we are calling the
function std.io.print from the standard library pulled in by the include
line at the start. The call statement passes arguments to a function using
the same syntax as stating a function to accept arguments. Here, we are
passing one argument, being the literal string 'Hello, World!' to the
function, and the function will print the text given.



Let's take a slightly more complicated example,

	include stdlib

	fn add ( a b ) x {
		x = "a + b"
	}

	fn main ( ) ret {
		ret = '0'

		x = call add ( '1' '2' )
	}

Here, we define the function add, which takes two arguments, a and b.
This function sets the variable x to the result of adding the two
arguments, and returns the variable x. In main, we then set the variable
x to the return value of the function call, being given arguments
1 and 2 as literal strings. In New Rock, the double quote marks an
expression that will be evaluated.

We can also allow a function to return multiple values like this:

	fn calculate ( a b ) add sub {
		add = "a + b"
		sub = "a - b"
	}

and we can call this function using

		x y = call calculate ( '3' '2' )

in this example, the variable x will be set to 5, and the variable y will
be set to 2. We can also use this idea to set multiple variables to the
same value with

		x y = '1'

In this, both variables x and y are equal to 1.



We can conditionally execute code using the if statement, which uses
a similar syntax to call:

		if ( "1 > 0" ) {
			x = 'one is greater than zero'
		}

In this example, we run the expression 1 > 0, and see if the result of it
is true or not. Since 1 is greater than zero, we set the variable x to
'one is greater than zero' as a literal string.

We can also use else if with another condition and else if all if and
else if both fail:

		if ( "5 > 10" ) {
			x = 'five is greater than ten'
		} else if ( "5 > 8" ) {
			x = 'five is greater than eight'
		} else if ( "5 > 6" ) {
			x = 'five is greater than six'
		} else {
			x = 'five is equal to five or less'
		}

In this example, we go through some cases. First, we test if 5 > 10, and
it is not, so we skip the body. Next, we test if 5 > 8, and it is not, so
we skip the body. Then, we test if 5 > 6, and it is not so we skip the
body. Finally, if all checks fail, then we run the else body.



The while keyword can be used to run looping code. In this example,
we create a basic loop

		x = '5'

		while ( "x != 0" ) {
			x = "x - 1"
		}

In this case, we set x to 5. Then, while x is not equal to 0, we decrement
x. After 5 iterations, x will be equal to 0, and the body of the while
will not run.



Functions are scoped locally, and cannot see or use variables from other
functions or ones that are defined globally by default. To allow a function
to see or set a global variable, we can use the import and export keywords

	x = '1'

	fn main ( ) ret {
		import x
		ret = x
	}

Here, we define the x variable in the global namespace. We then copy the
global variable x into the local namespace of the main function, and we
then set the local variable of main to x. If there are no quotes given
when setting the value of a variable, the value is assumed to be another
variable, and we copy the data of it. So in this case, ret = 1.

It is important to note the variable x that main sees is not a pointer
to the global variable x, but a copy of it. To export it back to the
global namespace, we must use export

	x = '1'

	fn main ( ) x {
		x = '2'
		export x
	}

In this case, we define the global variable x, then the local variable x to
main. We then copy the local variable x of main into the global namespace
as x.


You can place a comment in code using the '/' and '#' characters either
at the start or end of a line. A comment cannot be placed in the middle
of a line. Everything after the character is consitored the comment until
a newline is placed.


The New Rock standard library includes several useful functions. These are
mainly used to perform host-system interactions, such as printing, waiting,
multitasking, and so on. We will go over each library that exists in it
in order here:

	std.io.print - print formatted text
		This takes one argument, being a valid expression which
		will be resolved and automatically printed. If the data
		appears to be expression-like, it is evaluated as an
		expression using the same mechanisms as " in standard
		New Rock.

		Examples:

			include stdlib

			fn main ( ) x {
				x = '1 + 2'
				call std.io.print ( x ) 
				/ prints '3'
			}

			- - -

			include stdlib

			fn main ( ) x {
				x = 'Hello, World!'
				call std.io.print ( x )
				/ prints 'Hello, World!'
			}

			- - - 

			include stdlib

			fn main ( ) ret {
				ret = '0'
				call std.io.print ( 'Hello, World!' )
				/ same as above
			}

	std.io.printLn - print without a newline
		std.io.printLn is the same as std.io.print, but it des
		NOT append a newline to the end of the printed data

	std.io.printRaw - prints data without formatting
		std.io.printRaw will print data without the special
		formatting rules of print and printLn

		Examples:

			include stdlib

			fn main ( ) x {
				x = '1 + 2'
				call std.io.printRaw ( x )
				/ prints '1 + 2', no newline
			}

	std.io.input - request terminal input
		std.io.input will read from terminal input until a newline
		and return the data read. This will NOT echo the data typed
		from the terminal onto output. This will block until one
		newline (Enter) charatcer is pressed.

		Examples:

			include stdlib

			fn main ( ) input {
				input = call std.io.input ( )
			}

	std.misc.sleep - sleep for N milliseconds
		std.io.sleep will block and wait for the specified number
		of milliseconds (one millisecond is 1/1000th of a second,
		AKA 1000 milliseconds is 1 second). Depending on the
		implimentation, this may ask the task scheduler to run
		another task in the background (which will be discussed
		later in). This will return the real amount of time slept.

		Examples:

			include stdlib

			fn main ( ) time {
				time = call std.misc.sleep ( '500' )
				/ we have slept for half a second
				base = 'Slept for '
				text = "base s++ time s++ ms"
				call std.io.print ( text )
				/ s++ is concat(), so this
				/ resolves to  'Slept for [time]ms'
				/ where time is the variable time
			}

	std.misc.random - generate a random number
		This will return a NON-CRYPTOGRAPHIC platform-sized random
		number

		Examples:

			include stdlib

			fn main ( ) num {
				num = call std.misc.random ( )
				call std.io.print ( num )

				if ( "num > 500000" ) {
					call std.io.print ( 'big' )
				} else {
					call std.io.print ( 'small' )
				}
			}

		Or, to generate a secure private key, simply

			fn generateSecurePrivateKey ( ) key {
				key = '4'
			}
